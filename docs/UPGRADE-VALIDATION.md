## 经检查解决的问题

- 原乐器页脚本引用不存在的 `sample-upload`、`play-scale`、`instrument-log`；恢复原设计意图的控件和状态区。
- 原游戏只有 120/90 两档，缺少 GREAT、统计和暂停；换成统一 Web Audio 时钟、四档计分、真实结束时刻和完整结果。
- 原重复转场会与新转场同时截获点击；统一由共享导航控制，保留旧章节内容并停用旧遮罩。
- 普通 `python -m http.server` 不提供所需的音频 Range 响应，真实浏览器寻位受限；新增 `tools/serve.py` 并实测解决。
- 异步音频载入与试音可能竞争；准备就绪后才提交音频/谱面/采样，静音/停止/离页取消旧任务。
