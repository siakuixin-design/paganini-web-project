## 分阶段实施

1. 保存基线；检查全部页面、音频、脚本、导航与资料。
2. 并行制作两个可运行样板：Three.js 练习室（房间、模型、镜头、射线互动）和完整音乐挑战（同步、暂停、判定、80%、结算、重试、真实音高）。先浏览器验证联动再推广。
3. 使用同一场景/模型引擎扩展其他人生章节和乐器。保留原始叙事，日期以现有资料可支持的事件为限。Antonia Bianchi 与 Achille 是家庭线索，艺术化旁白不是史实对白。
4. 完整文字生平加入滚动场景与可点击时间轴。作品加入真实 AudioContext 分析器及明确缺谱状态/准确时间谱面接口。
5. 统一专属主题转场，封页剧场开场（首次会话、声音选择、跳过），保留所有入口和控件。
6. Chromium 实测：所有路由、媒体、WebGL/非 WebGL、点击拾取、游戏自动时序评分/失败/重试/暂停/结束/关卡限制、单一音乐播放、可视化、滚动、转场/返回及移动端。自动测试之外的耳听音色、精确谱面对拍和审美验收单列为人工检查。
