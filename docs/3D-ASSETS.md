# 三维场景与模型

## 当前可运行资源

Three.js r160 保存在 `assets/vendor/three.module.min.js`，不依赖 CDN。所有场景的建筑、房间、家具、地图标记、观众剪影、乐器均由 `assets/js/three-scenes-shared.js` 在浏览器中创建真实三维网格。它们是功能原型和艺术化环境，不是历史建筑复原或馆藏乐器数字扫描。

- `theatre-3d.js`：出生、练习室、少年音乐厅、欧洲巡演、晚年雨室、临终及序幕。
- `instrument-3d.js`：曼陀林、小提琴、吉他，各自独立几何轮廓、弦组和环境光；小提琴有简化琴弓。
- `theatre-3d.css`：三维窗口、加载状态、按钮、说明和窄屏布局。
- `three-scenes-shared.js`：木质材质、三维网格、镜头插值、WebGL 生命周期、弦与弓动画。

相机镜头和模型都处于真实 Three.js 三维坐标系中；场景物品使用 Raycaster 命中检测。等价 DOM 按钮可通过键盘操作，不要求鼠标点中小物件。练习琴身探索可进入现有音乐挑战，收到通过事件后表现昼夜变化；失败不会打开下一章原有通关门槛。

页面滚动离开三维窗口或切到后台时暂停绘制；页面离开释放几何体、材质和 renderer。初始化失败或 WebGL context 丢失时，保留原有图文/矢量图、说明和物品按钮，不阻塞原页面。减少动态效果会立即结束镜头插值并停止环境自动运动。

## 历史边界

- 出生：1782 年 10 月 27 日，热那亚。
- 卢卡：1801 年起在卢卡工作，1805 年进入埃莉萨·巴乔基宫廷。
- 欧洲：1828 年维也纳，1831 年巴黎和伦敦。地图是城市节点示意图，不是精确地理投影或完整行程。
- 家庭：Antonia Bianchi 为伴侣；Achille 1825 年出生于巴勒莫。不编写未经史料证实的家庭对话。
- 去世：1840 年 5 月 27 日，尼斯。窗外雨景及灯光为艺术表达。

参考核对入口：Grove Music / Oxford Music 的 Paganini 生平条目；Encyclopaedia Britannica 的 Niccolò Paganini 条目；热那亚 Museo Paganini 与 Comune di Genova 的生平资料。项目既有来源链接与原始传记仍保留。场景中没有将占位模型标注为历史实物。

## 后续高精度素材清单

1. 有清楚来源与许可的低面数 18 世纪热那亚街屋、练习室家具及剧院模型，建议 glTF/GLB。
2. 曼陀林、小提琴与古典吉他的独立弦组、琴弓及木纹 PBR 贴图；移动端可用 1K 纹理与 Draco/Meshopt 压缩。
3. 经过授权的人物模型与演奏动画。当前只用简化观众和家庭剪影，没有冒充人物肖像模型。
4. 历史地图贴图及其使用许可；当前用无外部贴图的立体示意路线。
5. 与音乐精确对应的演奏动作/MIDI，才能进一步做到逐音指法与弓法；当前动画只表示已发声的弦组反馈。

替换精细模型时保持 WebGL 失败的图文备用、键盘按钮、加载提示、音频事件与资源释放机制，并单独记录模型许可证。不要删除原有图片或音频作为替代。

## 临终落幕音乐

`scene07` 的“播放落幕音乐”仅在用户点击后使用已有 `assets/audio/works/cantabile.mp3`，通过 `Paganini.audio` 注册和播放。镜头拉远时按实际音频播放位置在七秒内将音量降到零；画面保留 `NICCOLÒ PAGANINI / 1782 — 1840`。这段配乐明确标注为可选的艺术化录音片段，不声称是历史场景的声音。新加的“音乐遗产与后世影响”按钮指向已有 `effects/effects.html`，原有前进链接仍保留。

全站静音、音频总线停止、页面进入后台及离页会取消淡出帧、暂停并清除音频来源。页面恢复不会自行重播。实际 Chromium 检查确认：未点击时暂停且无音频来源；点击后播放；约 2.54 秒时音量由 0.42 降至约 0.27；七秒淡出后暂停且清空来源；再次播放后总线停止同样清理来源；无页面 JavaScript 异常。此自动测试验证浏览器播放状态与音量变化，不代替扬声器试听。

## 打开方式与自由探索修正

直接双击 HTML 会使用 `file://`，浏览器会阻止本地 ES 模块载入，导致出现备用显示。这不等于场景不存在。Windows 请在完整解压后的项目根目录运行 `START-WEBSITE.bat`（需要 Python 3），它使用空闲端口启动本地服务并打开浏览器；也可运行 `python3 tools/serve.py --port 8000 --open`。

人生场景增加明确的自由探索模式：拖动环顾、聚焦画布后的 WASD／方向键、滚轮靠近远离、屏幕方向按钮以及返回剧情视角。移动有房间边界和家具碰撞约束；拖动不会误触剧情物品。原有点击物品与镜头叙事保留。

本机没有 Windows 执行器，批处理启动入口尚未在真实 Windows 中执行；Python 服务器空闲端口和静态三维模块的 HTTP 响应已实测。受管理的 Chromium 阻止 `file://` 页面，因此本机不能声称直接文件模式提示经过真实浏览器执行；其分支已做脚本检查。
